750B 순번 확인기

서울시 공공데이터 API로 750B의 오늘자 첫차시간을 조회하여 앞순번/뒷순번을 판별합니다.

❓ 설정 방법 안내

1단계: API 키 발급

  1. 공공데이터포털 회원가입 & 로그인
  2. 서울특별시_노선정보조회 서비스에서 활용신청
  3. 승인 후 마이페이지에서 Encoding 인증키 복사

2단계: Cloudflare Worker 배포

  1. Cloudflare 무료 가입
  2. Workers & Pages → Create Worker
  3. 함께 제공된 cloudflare-worker.js 코드를 붙여넣고 Deploy
  4. 배포된 URL을 위 입력란에 입력

3단계: GitHub Pages 호스팅

  1. GitHub에 새 저장소 생성
  2. 이 HTML 파일을 index.html로 업로드
  3. Settings → Pages → Branch: main → Save
  4. https://내아이디.github.io/저장소명/ 으로 접속

⚠️ 모든 키/URL은 브라우저 로컬에만 저장됩니다.

ℹ️ 작동 원리

getRouteInfo API가 750B의 금일 첫차시간(firstBusTm)을 매일 갱신하여 반환합니다.

첫차 04시대 → 앞순번 (첫차 조) · 첫차 05시대 → 뒷순번 (막차 조)

이 값은 서울시 TOPIS의 실제 운행 계획 기반이므로 2주 교대를 별도 계산할 필요 없이 오늘 기준 정확한 결과를 보여줍니다.

데이터 흐름: 브라우저 → Cloudflare Worker(https 중계) → 서울시 API(ws.bus.go.kr)

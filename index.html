750B 은평차고지 운행 확인

서울시 API로 750B 노선의 경유 정류소를 조회하여,
이번 주 은평차고지에서 750B가 출발하는지 확인합니다.

❓ 설정 방법 안내

1단계: API 키 발급

  1. 공공데이터포털 회원가입 & 로그인
  2. 서울특별시_노선정보조회 서비스에서 활용신청
  3. 승인 후 마이페이지에서 인증키 복사

2단계: Cloudflare Worker 배포

  1. Cloudflare 무료 가입
  2. Workers & Pages → Create Worker → Deploy
  3. Edit code → cloudflare-worker.js 코드 붙여넣기 → Deploy
  4. 배포된 URL을 위 입력란에 입력

⚠️ 모든 키/URL은 브라우저 로컬에만 저장됩니다.

ℹ️ 작동 원리

getStaionByRoute API로 750B 노선의 전체 경유 정류소 목록을 가져옵니다.

목록에 "은평차고지"가 포함되어 있으면 → 이번 주는 750B가 은평차고지에서 출발하는 주간입니다.

포함되어 있지 않으면 → 750A가 은평차고지에서 출발하는 주간이고, 750B는 봉천사거리 이후 일부 구간만 운행합니다.

이 교대는 격주 월요일에 일어나며, 매번 페이지를 열면 실시간 API 데이터로 확인합니다.
